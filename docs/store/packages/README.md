# Pacotes do Trail 1.4.6

- `trail-chrome-1.4.6.zip`: pacote de publicação para Chrome Web Store e Edge Add-ons. O `manifest.json` fica na raiz e mapas de código não são incluídos.
- `trail-extensao-1.4.6.zip`: cópia da pasta `trail-extensao/` para instalação manual em modo de desenvolvedor. Inclui `build.txt`; não deve ser enviada às lojas.

Ambos contêm o mesmo runtime 1.4.6. A diferença é somente a forma de empacotamento e o `build.txt` da instalação manual.

A 1.4.6 inclui tudo da 1.4.5 (que pode ser pulada nas lojas). A 1.4.4 não deve ser publicada: para usuários sem admin ela deixava mensagens vermelhas de acesso na sessão (bateria do PDI, 24/10/2026).
