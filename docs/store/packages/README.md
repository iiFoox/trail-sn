# Pacotes do Trail 1.4.4

- `trail-chrome-1.4.4.zip`: pacote de publicação para Chrome Web Store e Edge Add-ons. O `manifest.json` fica na raiz e mapas de código não são incluídos.
- `trail-extensao-1.4.4.zip`: cópia da pasta `trail-extensao/` para instalação manual em modo de desenvolvedor. Inclui mapas de código e `build.txt`; não deve ser enviada às lojas.

Ambos contêm o mesmo runtime 1.4.4. A diferença é somente a forma de empacotamento e os arquivos auxiliares da instalação manual.
